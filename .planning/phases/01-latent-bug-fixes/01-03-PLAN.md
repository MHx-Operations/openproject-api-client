<objective>
Close three behavior-cleanup bugs in one plan because they are small, localized, and share a single regression run:

- **BUG-03**: `Query.__init__` hardcodes `debug=True` (resources.py:582), causing every Query instance to carry a `self.json` attribute holding the full raw JSON payload and every `_links` / `_embedded` key smashed onto the namespace via lowercase. This leaks raw API blobs into CLI `json_out` output. Remove the `debug=True`.
- **BUG-04**: `get_workpackages(status=...)` silently ignores unknown status strings (apiclient.py:277-291) — the if/elif chain falls through with no filter applied and no error. This is undocumented. Lock the behavior as "silently passthrough (no filter applied)", document it in the docstring, and add a test.
- **BUG-05**: `get_workpackages_by_query_id` (apiclient.py:327) does not share the same `None`-result guard pattern as `get_paged_collection` (apiclient.py:163). Specifically, `result.results` is accessed before checking whether `result` is a WorkPackageCollection envelope vs. some other shape; an empty/None inner `collection` from the API can crash with AttributeError. Mirror the `get_paged_collection` guard.

**Intentional non-breaking-with-caveat (BUG-03):** removing `debug=True` from `Query` is a borderline behavior change. Any caller relying on `Query.json` or on the lowercased `_links`/`_embedded` keys will see those attributes disappear. CONCERNS.md flags this as "likely left over from development debugging and never cleaned up". Per the phase brief, this is an intentional cleanup; we document it in `docs/Status.md` as a v0.3 release note.

Purpose: Eliminate the last three latent bugs in the phase; document the one borderline behavior change.
Output: 4 small source edits, 3 new tests, 1 docs entry.
</objective>

def get_workpackages_by_query_id(self, query_id: int) -> list[res.WorkPackage]:
    workpackages = []
    page_size = 10
    payload={'pageSize': page_size}
    offset = 1
    while True:
        payload.update({'offset': offset})
        result = self.get(f"queries/{query_id}", payload=payload)
        if result:
            collection = result.results
            if isinstance(collection, res.WorkPackageCollection):
                workpackages += list(result.results)
                if collection.total < collection.offset * collection.pagesize:
                    break
                offset += 1
            else:
                break
        else:
            break
    return workpackages
