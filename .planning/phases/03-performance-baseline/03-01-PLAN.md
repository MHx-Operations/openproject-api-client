<objective>
Implement PERF-01: replace per-call `requests.<method>(...)` invocations in `ApiClient` with a single `requests.Session` reused for the instance lifetime. This eliminates per-request TCP/TLS reconnects and is a precondition for any future connection-pool tuning.

Purpose: A long-lived Session keeps the underlying HTTPS connection alive between calls (HTTP keep-alive + urllib3 pool), dropping latency from ~RTT+TLS-handshake per request to ~RTT per request.

Output: Modified `ApiClient` using `self._session`; new regression test asserting Session reuse.
</objective>
