<objective>
Implement PERF-02: raise `get_paged_collection`'s default `page_size` from `5` to `100`. This is a single-line default-parameter change. It is non-breaking — callers that pass an explicit `page_size` are unaffected; callers that rely on the default get larger pages (more efficient, identical result set).

Purpose: At the current default of 5, a project with 200 work packages requires 40 HTTP roundtrips. At 100, it requires 2.

Output: Bumped default, regression tests covering both the signature-level default and the on-the-wire effect, plus a release-note entry in docs/Status.md.
</objective>
