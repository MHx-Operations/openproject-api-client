## Naming Conventions

- **Packages / modules:** lowercase, no underscores where avoidable (`apiclient`, `resources`, `cli`). Package dir uses underscore: `openproject_api_client/`.
- **Classes:** `PascalCase` — `ApiClient`, `WorkPackage`, `WorkPackageCollection`, `ApiError`.
- **Methods / functions:** `snake_case` — `get_workpackages_by_project_id`, `create_time_entry`.
- **Raw HTTP wrappers:** `http_` prefix (`http_get`, `http_post`, `http_patch`, `http_delete`) — distinct from `get` / `post` / `patch` / `delete` which decode the response.
- **Resource methods:** `get_<resource>` (single) vs `get_<resources>` (list); write verbs are `create_`, `update_`, `delete_`, plus a couple of one-offs (`add_workpackage_comment`, `mark_notification_read`).
- **Test files:** `test_<module>.py` (one per source module, plus extras).
- **Test classes:** `TestApiClientInit`, `TestGetWorkpackages`, etc. — grouped by feature, optional.
- **JSON → attribute mapping:** API returns camelCase; resource models lowercase the key (`createdAt` → `obj.createdat`). Not snake_case.
- **Keyword-only writes:** `create_workpackage` and `update_*` methods use `*` to force keyword args for clarity (`apiclient.py:525`, `:576`, etc.).
- **Private helpers:** leading underscore (`_endpoint`, `_headers`, `_obj_to_dict`, `__parse_datetime`).

## Where to Add New Code

| Task | Where |
|---|---|
| New API resource | (1) Add class in `openproject_api_client/resources.py`, (2) register in `decode` dispatch (`apiclient.py:208`), (3) add to `__all__` in both files, (4) add `get_*` / `create_*` methods on `ApiClient`. |
| New CLI subcommand | Add subparser in `cli.py:main()`; add branch in `dispatch()`. |
| New HTTP method | Should not be needed — funnel through `http_get/post/patch/delete`. |
| New shared test fixture | Add to `tests/conftest.py`. |
| Module-level imports | Re-export from `openproject_api_client/__init__.py` for public API. |
| Examples | Drop a script under `examples/`. |
| Documentation | Markdown files under `docs/`. |

## Files That Do Not Belong to Runtime

- `openproject-api-client.iml` — IntelliJ/PyCharm project file.
- `openproject_api_client.egg-info/` — generated by editable install; safe to ignore.
- `setup.py` — minimal shim retained for legacy `pip install -e .`; real config lives in `pyproject.toml`.
